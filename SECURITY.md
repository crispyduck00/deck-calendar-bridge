# Security and privacy

Rules are administrator-controlled delegations across Deck and calendar permissions. Do not expose generic cross-app write endpoints or authorize reverse updates from a participant copy. Validate the exact original identity and preserve ETag and source-snapshot checks.

Use GitHub private vulnerability reporting if it is available for the repository. Otherwise contact a repository maintainer through GitHub before posting exploit details. Never publish credentials, unredacted calendar objects, personal card content or server configuration in an issue.

Support is scoped to the versions listed in the README. Install reviewed release packages and keep Nextcloud, Deck and PHP maintained. Repository cleanup and public-source preparation are separate from uninstalling the Nextcloud app; the maintenance scripts do not connect to a Nextcloud server.
